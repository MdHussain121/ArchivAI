# Privacy Policy for ArchivAI

Last updated: June 12, 2026

## Data Collection
ArchivAI collects and stores the following data locally in your browser:
- URLs and titles of web pages you choose to save
- Full text content of saved pages (for offline reading and AI analysis)
- Your Nvidia NIM API key (stored securely in Chrome's local storage)

## How Data Is Used
- Page content is sent to Nvidia NIM API for AI-powered tagging, categorization, and summarization ONLY when you save a page
- All data is stored locally in your browser's IndexedDB and Chrome storage
- No data is sent to any server other than the Nvidia NIM API (for AI processing)
- No data is shared with third parties
- No analytics or tracking is implemented

## Data Storage
- Bookmarks and page content: IndexedDB (local browser storage)
- API key and preferences: chrome.storage.local
- All data remains on your device
- Data persists until you delete it or uninstall the extension

## User Control
- You can delete individual bookmarks at any time
- You can export all your data as JSON, CSV, or TXT
- Uninstalling the extension removes all stored data
- Your Nvidia NIM API key is never shared or transmitted except to Nvidia's API

## Third-Party Services
This extension uses Nvidia NIM API (integrate.api.nvidia.com) for AI analysis. When you save a page, its content is sent to Nvidia for processing. Nvidia's data handling policies apply to this data. See: https://build.nvidia.com/

## Contact
For privacy questions, please open an issue on the extension's GitHub repository.
