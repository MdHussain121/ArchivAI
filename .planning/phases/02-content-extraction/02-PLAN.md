# Phase 2: Content Extraction & Save Flow

## Goal
One-click save that extracts page content and stores it locally.

## Tasks Completed
- Content script extracts title, URL, OG meta, full text
- Readability-light text extraction
- Popup save UI with neo-brutalism
- Popup → content script → background → IndexedDB save flow
- Context menu save (right-click)
- Auto-dedup on same URL

## Remaining

- Keyboard shortcuts for quick save
